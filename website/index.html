Rbitnet

Pure-Rust GGUF inference — OpenAI-compatible API, native BitNet path, no external engine at runtime.

Install Documentation

A warren for bits

Rbitnet memory-maps the GGUF, runs the transformer, and serves tokens over an OpenAI-compatible API on port 8080. The whole runtime is Rust.

What ships today

  • bitnet-core Llama / Qwen3 / BitNet b1.58 GGUF, CPU quantized kernels, paged & quantized KV hooks.
  • rbitnet-server OpenAI /v1 HTTP, SSE streaming, health / ready / Prometheus metrics, hot reload.
  • rbitnet CLI Curated catalog, Hub download, quickstart, TUI chat, BitNet recipes, optional train helpers.

What's new in 0.2.0

Released 8 October 2026. The everyday path is unchanged: install, download a GGUF, rbitnet serve. The new pieces are opt-in and aimed at an NVIDIA GPU.

  • CUDA Llama serving Several chat requests can share GPU projections. Turn on continuous batching and fused multi-seq. Live per-token streaming is a separate opt-in.
  • Prompt restore Llama and Qwen prefixes can sit in RAM, then on disk. A measured Llama 3.2 1B prompt returned in tens of milliseconds instead of a full recompute.
  • Block prefill CUDA block prefill for Llama, Qwen, GPT-OSS, and GLM, plus paged KV so a 16 GiB GPU can hold more than one Llama request.

Roadmap focus

CPU remains the default when no NVIDIA GPU is present. 0.2.0 closed the Llama CUDA serving slice. The next work is the same idea on Qwen and MoE models.

  • Near term Live SSE and adaptive admission are opt-in on Llama CUDA. Publish the same 1/4/8 numbers on your own GPU before you rely on them.
  • Next Shared multi-request decode for Qwen and for GPT-OSS / GLM experts. CUDA graphs stay experimental.
  • Not in this release Grammar-constrained JSON, image chat, and Vulkan / Metal inference.

Install

One checkout, one binary. Python only if you convert checkpoints to GGUF upstream.

curl -fsSL https://raw.githubusercontent.com/azerothl/Rbitnet/main/scripts/install.sh | sh
rbitnet models install tinyllama:q4 --dir ./models
rbitnet up tinyllama:q4 --dir ./models
rbitnet serve

Windows: .\scripts\install.ps1 · User guide · FR quickstart
