Rbitnet

Moteur GGUF en Rust pur — API OpenAI-compatible, BitNet natif, zéro moteur d’inférence externe.

Installer Documentation

Un terrier pour les bits

Rbitnet mmap le GGUF, déquantifie, exécute le transformer et sert des tokens — self-sufficient en Rust, conçu comme backend satellite pour Akasha.

Ce qui tourne aujourd’hui

  • bitnet-core GGUF Llama / Qwen3 / BitNet b1.58, kernels quantifiés CPU, KV paged & quantifié.
  • rbitnet-server HTTP OpenAI /v1, SSE, health / ready / metrics, reload à chaud.
  • rbitnet CLI Catalogue, download, quickstart, TUI chat, recipes BitNet.

Démarrer

Un checkout, un binaire. Python seulement si vous convertissez des checkpoints en GGUF.

curl -fsSL https://raw.githubusercontent.com/azerothl/Rbitnet/main/scripts/install.sh | sh
rbitnet quickstart
rbitnet-server

Windows : .\scripts\install.ps1 · Docs : démarrage 5 min

Dans la stack Akasha

akasha-os garde llama.cpp dans le TCB Preview. Le daemon Akasha consomme Rbitnet en HTTP sur le port 8080 — rôles séparés, contrat /v1 + /metrics gelé.
